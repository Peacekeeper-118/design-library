# design-library

Sample designs, tokens and templates, refreshed weekly.

- `astryx/`: a weekly copy of the open-source design system [meta/astryx](https://github.com/meta/astryx) (MIT License; notice in `NOTICE`, license text in `astryx/LICENSE`).
- Other folders: original designs and templates by the owner.

Each weekly refresh arrives as a branch named `weekly/<date>` and is merged by the owner after review.
